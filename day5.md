# Assignment 5 - GitHub Repository Link Proof

In this assignment, you need to push your local Git repository to GitHub and provide the public repository link as proof[span_1](start_span)[span_1](end_span).

## Steps
1. Create a new repository on GitHub (public or private).
2. In your local terminal, add the remote URL:
   `git remote add origin <your-repository-url>`
3. Set your default branch name to main:
   `git branch -M main`
4. Push your code to GitHub:
   `git push -u origin main`
